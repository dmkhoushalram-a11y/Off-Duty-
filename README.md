# OFF DUTY Storefront Demonstration

An independent, unofficial student project inspired by OFF DUTY. It is not operated, authorized, affiliated with, or endorsed by OFF DUTY. Brand names, logos, product imagery, and reference prices belong to their respective owners and are included for educational demonstration. This site does not offer sales, orders, payments, or fulfilment.

## Run locally

Open `index.html` in a browser, or use a static server from this folder:

```powershell
python -m http.server 4173
```

The site is plain HTML, CSS, and JavaScript; it has no build step or server-side requirements. Product/catalog interactions are frontend demonstrations only. Some editorial images load from Unsplash and require internet access.
